# B-03 测试指南

> 本模组无自动化测试框架，测试 = **编译验证 + 游戏内实测 + 日志检查**。

## 一、编译验证（每次改动后必做）

```powershell
$env:DOTNET_CLI_HOME = "D:\CODE\rim\Clap_Your_Hands\.dsh-dotnet"
dotnet build "Clap_Your_Hands\Clap_Your_Hands.csproj" -v minimal
```

**通过标准**：`已成功生成` + `0 个警告` + `0 个错误`，且 `Clap_Your_Hands/Assemblies/Clap_Your_Hands.dll` 时间戳更新。

## 二、XML 解析验证

```powershell
Get-ChildItem -Recurse "Clap_Your_Hands\Defs" -Filter *.xml | ForEach-Object {
  try { [xml](Get-Content $_.FullName) | Out-Null; "OK   $($_.Name)" }
  catch { "FAIL $($_.Name): $_" }
}
```

## 三、游戏内测试流程

1. 游戏加载到主菜单 → 开发模式开启 → 模组列表中启用本模组
2. **检查加载日志无红字**：检索 `Player.log` 中的 `Clap` 与 `[ClapYourHands]`
3. 进入殖民地（或开发者模式快速开局），准备 2 名以上可社交的殖民者
4. 观察社交日志中是否出现击掌互动
5. 用调试指令（若有）强制触发各档结果，逐项核对效果

### 检查清单

| # | 检查项 | 期望 |
| --- | --- | --- |
| 1 | 模组加载 | 无红字，`[ClapYourHands] loaded.` 出现 |
| 2 | Def 加载 | 无「Could not find def」「Duplicate defName」类错误 |
| 3 | 自动触发 | 社交日志出现击掌，频率不刷屏 |
| 4 | 四档结果 | 均能出现，比例接近基础权重（小样本需耐心） |
| 5 | 情绪 | 糟糕 −3 / 普通 0 / 不错 +3 / 完美 +10 |
| 6 | 好感度 | 不错 / 完美后双方 opinion 上升（注意 `SocialImpact` 缩放） |
| 7 | 12h 增益 | 工作速度与移速变化与档位匹配，时长 12h |
| 8 | 增益叠加 | 高级覆盖低级；同级覆盖时长；低级不动高级 |
| 9 | 冷却 | 冷却中不再击掌；OR 判定行为符合预期 |
| 10 | 排除 | 敌对 / 仇视关系不触发 |
| 11 | 存读档 | 冷却与增益状态保持正确 |

## 四、日志检查

```powershell
Select-String -Path "<RimWorld 目录>\Player.log" -Pattern "Clap|clap" -Context 2,2
```

重点关注：`Exception`、`Could not find`、`Duplicate`、本模组前缀的 `Log.Error`。

## 五、回归重点

改动以下内容时必须重跑清单：`InteractionDef`/`HediffDef`/`ThoughtDef` 的 defName 或字段、概率常量、冷却逻辑、`ExposeData` 结构。
