# docs — 项目文档体系

> 本目录为 Clap Your Hands 的规范与知识文档库。权威源为根目录 `AGENTS.md`；原版 API 证据见 `docs/C/C-05-原版API简述.md`。

## 目录结构

```
docs/
├── A/  项目基准    — 需求与设计（PRD、数值设计）
├── B/  开发运维    — 开发规范、测试指南、BUG 知识库
├── C/  知识沉淀    — 代码 Wiki、架构详解、项目长期记忆、原版 API 简述、术语表
├── D/  方案设计    — （按需）新方案设计文档
└── E/  分析优化    — （按需）代码耦合度/性能分析
```

## 使用约定

- 新增规范先入 `AGENTS.md`，再展开到 `B-01-开发规范.md`
- 修复典型 Bug 记录到 `B-04-BUG知识库.md`，根因是规范缺失时反哺 B-01 与 `AGENTS.md`
- 新的原版 API 事实（反编译核实）一律追加到 `C-05-原版API简述.md`
